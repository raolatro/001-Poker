# 🃏 RaoLatro - Game Dev Journey

Welcome to **RaoLatro**, a poker-inspired mini game built with **LÖVE2D** in **Lua**.  
This is my very first game project and a part of my self-taught journey into game development.  
The project is heavily inspired by the addictively fun mechanics of **Balatro**, but this is **not a clone**—it's a learning experiment, with lots of personal touches and twists coming soon!

---

## 🎮 Game Concept

- A simplified, single-player poker-style game
- Play hands, discard cards, and chase high scores
- Designed as a stepping stone to learn game logic, animations, and game loops

---

## 🚧 Features (in progress)

✅ Playable poker hands  
✅ Discard and draw mechanics  
✅ Score system  
✅ Game Over screen  
✅ Start/Restart flow  
🔜 Combo multipliers  
🔜 Visual FX and SFX  
🔜 Special deck and cards  
🔜 Public release, maybe...

---

## 🛠 Built With

- [LÖVE2D](https://love2d.org/) – the framework powering the game
- **Lua** – scripting language used for all game logic
- **Aseprite** & **Photoshop** – for pixel art assets and UI
- **Audacity** – sound design
- [GitHub](https://github.com/raolatro) – version control and sanity saver
