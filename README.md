# 🃏 RaoLatro - My First Game Dev Test

> A solo dev experiment born out of a recent **Balatro addiction**,  
> and a desire to finally start making indie games — with **AI as my co-pilot**.

---

## 🎯 The Real Goal

This project isn't about creating the next hit game (yet 😅).  
It’s about learning **how games are actually made** — one step at a time.

**RaoLatro** is my very first attempt at building something playable from scratch.  
It’s a super early, rough prototype—held together with Lua, duct tape, determination,  
and a **whole lot of AI support**.

---

## 🤖 How AI Is Helping

I'm using AI at almost every step to:

- Understand and write Lua code
- Break down complex game logic into manageable chunks
- Debug issues and optimize structure
- Learn faster through trial, feedback, and iteration
- Explore new ideas and test mechanics on the fly
- Keep me motivated and moving forward

It’s like having a senior dev, tutor, and cheerleader all in one.  
This setup lets me **focus more on creativity and experimentation**, without getting stuck for hours.

---

## 🚀 Why I'm Doing This

Like many of us, I got *hooked* on **Balatro** recently.  
I couldn’t stop playing it — and then I had this moment:  
_“Wait… what if I tried building games like this myself?”_

So here we are.  
I’ve been a creative for almost two decades (design, animation, branding, video editing...),  
but I’ve never really made a game. This is the beginning of that journey.

---

## 🔧 What I'm Learning

This project is teaching me:

- How to structure a game using **Lua + LÖVE2D**, then eventually branch into other engines and languages
- How to manage **states**, **animations**, **databases**, and **user input**
- How to **debug** efficiently and stay unstuck
- How to properly use **GitHub** as part of the dev workflow
- How to ship small, scrappy things and keep building from there

---

## 🛠 Tech Stack

- **LÖVE2D** – The framework behind everything
- **Lua** – The main coding language
- **ChatGPT** – AI assistant for learning, debugging, and generating ideas and assets
- **Aseprite** / **Photoshop** – For quick pixel art and assets
- **Adobe Audition** – For sound design (in progress)
- **GitHub** – For version control (learning as I go)

---

## 🎮 Current Features (Simple But Working!)

- Playable poker hands
- Basic discard + draw mechanic
- Total score display
- Game Over + Restart flow
- Debug mode + simple SFX system

## 🖥 Run Locally

Make sure you have [LÖVE2D](https://love2d.org/) installed, then:

```bash
git clone https://github.com/raolatro/rao-poker.git
cd rao-poker
love .
```
